# Loan Management System

A desktop-based Loan Management System developed using JavaFX and Oracle Database. This application helps manage customers, loans, EMI payments, and authentication through an easy-to-use graphical interface.

## Features

- User Login
- User Registration
- Customer Management
- Loan Application
- EMI Calculation
- Payment Tracking
- Dashboard
- Oracle Database Connectivity
